# 首页改版设计：周热量进度 + 体重隐私化

日期: 2026-03-22

## 背景

用户不希望体重数据在首页被一眼看到，同时希望首页聚焦于按周维度的热量进度追踪，类似 GitHub contribution graph 的方块风格。

## 设计决策

| 决策项 | 选择 |
|--------|------|
| 体重数据位置 | 全部移到设置页，首页不显示任何体重信息 |
| 减脂进度卡片 | 移到设置页 |
| 周进度图风格 | 方案A：线性方块条（进度条 + 7日方块） |
| 周预算逻辑 | 周内动态分配（周总预算固定，单日可超但周总不超） |
| 日块颜色逻辑 | 混合指示（颜色基于原始日目标，箭头指示周剩余均值趋势） |
| 首页其他内容 | 全部保留，只移除体重相关 |
| 设置页组织 | 分区卡片：个人信息 + 减脂进度 + AI设置 |

## 一、首页改造

### 移除项

- 减脂进度卡片（进度百分比 + 起始/目标体重）
- 当前体重统计卡片（第4个统计卡片）
- 体重趋势折线图（DashboardCharts 中的 WeightTrendChart）

### 新增组件：WeeklyCalorieProgress

位置：首页最顶部，日期导航器下方。

**视觉结构：**

```
┌──────────────────────────────────────────────┐
│  本周热量预算                                  │
│  [████████████████░░░░░░░░░░░░░░░] 44%       │
│  5,550 / 12,600 kcal                         │
│                                               │
│  周一    周二    周三    周四    周五    周六    周日 │
│  ┌───┐  ┌───┐  ┌───┐  ┌───┐  ┌───┐  ┌───┐  ┌───┐│
│  │███│  │███│  │▓▓▓│  │   │  │   │  │   │  │   ││
│  └───┘  └───┘  └───┘  └───┘  └───┘  └───┘  └───┘│
│  1800   2100   1650    --     --     --     --   │
│   ↓      ↑      ↓                                │
│  剩余均值: 1,763 kcal/天                        │
└──────────────────────────────────────────────┘
```

**核心逻辑：**

- 周总预算 = 每日热量目标 x 7
- 已过去的天取实际摄入，未来的天留空
- 方块填充色对比原始日目标：绿(<=100%) / 黄(100-110%) / 红(>110%)
- 方块下方箭头：↓ 当日 < 周剩余均值，↑ 当日 > 周剩余均值
- 剩余均值 = (周总预算 - 已摄入总量) / 剩余天数
- 今日方块有高亮边框
- 点击方块跳转到该日详情（复用 DateNavigator）

### 首页组件顺序（改造后）

1. 日期导航器（DateNavigator）
2. **周热量进度图（WeeklyCalorieProgress）** [新增]
3. 统计卡片网格（3个：摄入热量、蛋白质、运动消耗）
4. 智能行动计划
5. 热量趋势柱状图
6. 健康提示

## 二、设置页改造

Settings 从纯 AI 配置弹窗扩展为完整设置页面，分三个卡片区：

### 个人信息区

- 展示 profile 数据：当前体重、身高、年龄、起始/目标体重、活动水平
- 体重记录入口（打开 WeightLogger 弹窗）
- 编辑个人信息入口（打开 SetupScreen 编辑模式）

### 减脂进度区

- 从首页搬来的进度条（起始体重 → 目标体重百分比）
- 进度元数据：已坚持天数、平均每周减重、预计剩余天数
- 体重趋势折线图（从 DashboardCharts 搬来）
- 最近体重记录列表

### AI 设置区

- 保持现有 AI API 配置不变

## 三、数据层

不需要改动数据模型（state.profile / state.dailyLogs / state.weightHistory 均已存在）。

### 新增工具函数

`getWeeklyCalorieData(state, date)` → 返回：

```js
{
  weekStart: '2026-03-16',   // 周一日期
  weekEnd: '2026-03-22',     // 周日日期
  dailyTarget: 1800,         // 每日热量目标
  weeklyBudget: 12600,       // 周总预算
  totalConsumed: 5550,        // 已摄入总量
  remainingAvg: 1763,         // 剩余均值
  days: [
    { date: '2026-03-16', dayLabel: '周一', calories: 1800, status: 'on_track', vsBudgetAvg: 'below' },
    { date: '2026-03-17', dayLabel: '周二', calories: 2100, status: 'over', vsBudgetAvg: 'above' },
    // ...
  ]
}
```
